# Sitio Web Responsivo - GitHub Pages

Este es un ejemplo de sitio web responsivo implementando todas las técnicas vistas en la materia:

## 🚀 Características implementadas

### HTML Semántico
- Uso de etiquetas semánticas (header, main, section, footer)
- Estructura jerárquica correcta
- Metadatos para SEO y responsividad

### CSS Moderno
- **Variables CSS** para colores y valores reutilizables
- **Flexbox** para layouts flexibles
- **CSS Grid** para estructuras más complejas
- **Media Queries** para diseño responsivo
- **Mobile First Approach** - Priorizando dispositivos móviles

### Responsive Design
- Puntos de ruptura:
  - Móvil: < 768px
  - Tableta: ≥ 768px
  - Escritorio: ≥ 1024px
- Imágenes responsivas
- Menú adaptable

### JavaScript
- Navegación suave (smooth scrolling)
- Menú móvil interactivo
- Fecha dinámica

### GitHub Pages
- Despliegue automático
- HTTPS gratuito
- Dominio personalizable
